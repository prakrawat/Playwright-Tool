After Installation Git Bash

1. git config --global user.name "prakashrawat999"
2. git config --global user.email "gollurwt143@gmail.com"
3. git config --list // To verify the configuration settings
4. git fetch // To fetch the latest changes from the remote repository
5. git pull // To pull the latest changes from the remote repository
6. git add . // To stage all changes for commit
7. git add <file_name> // To stage specific files for commit
8. git commit -m "Comment Add" // To commit the staged changes with a message
9. git push // To push the committed changes to the remote repository
10. git status // To check the status of the working directory and staging area
11. git log // To view the commit history
12. git branch // To list all branches in the repository
13. git checkout <branch_name> // To switch to a different branch
14. git merge <branch_name> // To merge a branch into the current branch
15. git checkout -b <new_branch_name> // To create and switch to a new branch
